# VISUAL.md

# Premium Visual System

This project is not a template portfolio.

It is a premium product experience.

Every pixel should communicate craftsmanship, confidence, engineering excellence, and attention to detail.

The user should immediately think:

> "Someone obsessed over every interaction."

The portfolio should feel closer to a modern operating system than a marketing website.

# Overall Feeling

The website should feel:

- expensive
- intelligent
- effortless
- calm
- premium
- futuristic
- fast
- elegant

Never loud.

Never gimmicky.

Never cluttered.

---

# First Impression

Within the first three seconds the visitor should feel:

"This engineer builds products at an exceptional level."

Everything above the fold should reinforce that feeling.

---

# Visual Density

Prefer empty space over more components.

Whitespace creates luxury.

Never fill space because it exists.

Every component earns its place.

---

# Typography

Typography is the design.

Large editorial headlines.

Comfortable reading width.

Large line height.

Excellent letter spacing.

Balanced font weights.

Avoid heavy fonts.

Avoid long paragraphs.

Ideal rhythm:

Display
↓

Heading
↓

Supporting copy
↓

CTA

Nothing else.

---

# Color System

Mostly neutral.

Allow color only where attention is needed.

The interface should work even if all accent colors are removed.

Accent colors should guide—not decorate.

Backgrounds should have subtle tonal variation.

Avoid saturated gradients.

Avoid rainbow effects.

---

# Glass Effects

Glass should be subtle.

Never imitate Windows Vista.

Use:

- low opacity
- soft blur
- thin border
- slight highlight
- minimal reflection

Glass exists only to separate layers.

---

# Shadows

Soft.

Wide.

Natural.

Never harsh.

Prefer multiple layered shadows instead of one large shadow.

Large elevation should remain elegant.

---

# Borders

Use borders sparingly.

1px.

Very low contrast.

The interface should rely on spacing before borders.

---

# Corners

Consistent radius system.

Examples:

4px

8px

12px

16px

24px

Never random.

---

# Spacing

Follow an 8px grid.

Every section breathes.

Every card breathes.

Every button breathes.

Large whitespace creates perceived quality.

---

# Layout

Content width should feel intentional.

Avoid stretching text.

Use asymmetry where appropriate.

Perfect alignment matters.

Grid systems should disappear into the design.

---

# Motion Philosophy

Motion should feel invisible.

Animation exists to communicate.

Never to entertain.

Every transition should have purpose.

---

# Motion Timing

Preferred durations:

120ms

180ms

240ms

320ms

500ms

Preferred easing:

cubic-bezier(0.16, 1, 0.3, 1)

Avoid:

Bounce

Elastic

Overshoot

Rubber-band

---

# Premium Hover States

Hover should feel physical.

Buttons should slightly brighten.

Cards should gently lift.

Images should subtly zoom.

Text should slightly increase opacity.

Never dramatic scaling.

Maximum scale:

1.02

---

# Cursor Experience

Cursor interactions should feel intentional.

Allow subtle magnetic attraction for important buttons.

Cursor trails must remain subtle.

Avoid novelty cursor effects.

---

# Scroll Experience

Scrolling should feel like premium native software.

Use smooth scrolling.

No jumpy animations.

No scroll hijacking.

Elements should enter naturally.

Different layers should move at subtly different speeds.

Maintain 60 FPS.

Scrolling should feel weightless.

---

# Scroll Reveal

Reveal only once.

Use:

opacity

translateY

blur reduction

Avoid:

rotation

spin

bounce

large scale

Animation should finish before the user notices it started.

---

# Hero Section

The hero defines quality.

Large typography.

Minimal copy.

Strong visual hierarchy.

Beautiful spacing.

One memorable interaction.

One premium visual centerpiece.

Avoid adding multiple competing elements.

---

# Background System

Backgrounds should never be flat.

Use extremely subtle gradients.

Soft radial lighting.

Tiny amounts of visual noise.

Occasional glow.

Everything should remain understated.

---

# Lighting

Imagine the interface is lit by soft studio lighting.

Top light.

Gentle highlights.

Soft ambient shadows.

No neon overload.

---

# Visual Depth

Create depth through:

blur

lighting

spacing

layering

shadows

Never rely on excessive borders.

---

# Cards

Cards should feel lightweight.

Floating.

Breathing.

Minimal decoration.

Padding is more important than borders.

---

# Images

Images should feel premium.

Rounded corners.

Soft shadows.

Excellent cropping.

Avoid generic mockups.

Avoid stock photography.

---

# Buttons

Buttons should feel tactile.

Perfect padding.

Clear hierarchy.

Fast feedback.

Subtle hover.

Subtle press.

Visible keyboard focus.

---

# Navigation

Navigation should disappear into the experience.

Compact.

Elegant.

Minimal.

Smooth active states.

Sticky only when it improves usability.

---

# Mouse Movement

Use mouse movement sparingly.

Hero visuals may respond slightly.

Maximum movement:

8–12px

Avoid dramatic parallax.

# Performance Rules

Every animation must stay GPU accelerated.

Animate only:

transform

opacity

filter (minimal)

Never animate layout.

Avoid repaint-heavy effects.

Maintain excellent Lighthouse scores.

---

# Accessibility

Every animation respects prefers-reduced-motion.

Keyboard users receive equal experience.

Focus indicators are beautiful.

Contrast always passes WCAG.

Screen readers understand every interaction.

---

# Engineering Quality

Every section should feel handcrafted.

Every component reusable.

Every animation intentional.

Every pixel aligned.

Every spacing value consistent.

Every interaction polished.

Nothing should feel accidental.
